# モコの きおく ゲーム 仕様 v0.1

> 2026-11 作成。**まだ 実装しない**（決まったら Go）。
> おぼえて こたえる ゲームを 3つ。① くだものの おさら ② マスの きおく ③ ペアさがし（おすすめ）。
> 「決めてほしいこと」（さいご）に 推奨案を つけています。

---

## 0. ぜんたいの方針
- **あたらしい へや `kioku/`**（独立フォルダ。ES Modules ＋ `common/core.js`）。おうちの「おべんきょう」に カードを 1まい 足す（入口リンクだけ）。
- **むずかしさは じどうで かわる**：3もん つづけて せいかい → レベル＋1、2もん つづけて まちがい → レベル−1。どの ゲームも Lv1〜10。
- **こたえる ときは じかん せいげん なし**（おぼえる 時間だけ 決まっている）。あせらせない。
- **1かい ＝ 5もん**。おわると ⭐ と けっか（レベルの メーター）。
- もんだい文は **よみあげ**（`speechSynthesis` ja-JP。🔊で もう いちど）。字が まだ にがてでも あそべる。
- 絵は すべて コードで描く（SVG）。文字は ひらがな中心。iPad の たて・よこ どちらでも。

## ① くだものの おさら（みた ものを おぼえる）

### 流れ
1. テーブルの うえの おさらに くだものが ならぶ（「よーく みてね」＋ のこり時間の バー）。
2. 時間に なると **ぬのが ふわっと かぶさって** 見えなくなる。
3. もんだいが でる → こたえる → ぬのを とって 「こたえあわせ」（せいかいの くだものが ひかる）。

### くだもの（SVG で 12しゅるい）
りんご・バナナ・ぶどう・いちご・みかん・メロン・もも・さくらんぼ・パイナップル・キウイ・すいか・レモン。
（えいごの へやと つながるよう、データに `en` も もたせる。ゲーム中は ひらがなだけ）

### もんだいの しゅるい（レベルで ふえる）
| しゅるい | もんだい | こたえかた | でる レベル |
|---|---|---|---|
| あった？ | 「🍎 は あった？」 | あった ／ なかった | 1〜 |
| なにが あった？ | 「あった くだものを 1つ えらんでね」 | 3〜4この なかから 1つ | 1〜 |
| なくなった | もう いちど みせる。1つ へっている。「なにが なくなった？」 | えらぶ | 2〜 |
| いくつ？ | 「🍓 は いくつ あった？」（おなじ くだものが ふくすう） | 1〜5 の ボタン | 3〜 |
| じゅんばん（○ばんめ） | よこ 1れつに ならぶ。「ひだりから 2ばんめは？」 | えらぶ | 4〜 |
| じゅんばん（ならべる） | 「みた じゅんばんに タップしてね」 | じゅんに タップ | 6〜 |
| ふえた・いれかわった | もう いちど みせる。1つ ふえた／2つ いれかわった | ふえた もの／いれかわった 2つを タップ | 8〜 |

### レベルの めやす
| Lv | くだものの かず | みる 時間 | ならびかた |
|---|---|---|---|
| 1 | 3 | 5びょう | おさらに ばらばら |
| 2〜3 | 4 | 5びょう | 〃（3から おなじ くだものも） |
| 4〜5 | 5 | 6びょう | よこ 1れつ も でる |
| 6〜7 | 6 | 6びょう | 〃 |
| 8〜10 | 7〜8 | 7びょう | 〃 |

- みる 時間は ⚙️せってい で「ゆっくり（1.5ばい）／ふつう／はやい（0.8ばい）」。
- まちがいの せんたくしは「にた いろ・にた かたち」を まぜる（りんご↔さくらんぼ、みかん↔レモン など）。

## ② マスの きおく（どこに あった？）

### 流れ
1. マス目の うえに マーク（⭐ ハート など）が ぱっと でる（「どこかな？ おぼえてね」）。
2. 時間に なると マークが きえる。
3. マークが あった マスを タップ。ぜんぶ タップしたら こたえあわせ（あたり＝マークが ポン、はずれ＝×）。

### レベル
| Lv | マス | マークの かず | みる 時間 | そのほか |
|---|---|---|---|---|
| 1 | 2×2 | 1 | 3びょう | |
| 2 | 3×3 | 2 | 3びょう | |
| 3 | 3×3 | 3 | 4びょう | |
| 4 | 4×4 | 3 | 4びょう | |
| 5 | 4×4 | 4 | 5びょう | |
| 6 | 4×4 | 4 | 5びょう | マークが 2しゅるい → 「ハートだけ タップ」 |
| 7 | 5×5 | 5 | 5びょう | |
| 8 | 5×5 | 5 | 5びょう | 2しゅるい |
| 9 | 5×5 | 5 | 5びょう | **じゅんばん**：1つずつ ひかる → ひかった じゅんに タップ |
| 10 | 6×6 | 6 | 6びょう | 2しゅるい |

- タップは マークの かずだけ（それ以上は おせない）。まちがえた マスは 「×」、さいごに せいかいの マスを みせる。
- ⭐3＝ぜんぶ あたり、⭐1＝はんぶん いじょう（ほめる ポイントを つくる）。レベルが あがるのは「ぜんぶ あたり」だけ。

## ③ ペアさがし（おすすめ：しんけいすいじゃく × べんきょう）

**おすすめ の りゆう**：みんな しっている あそびで ルールの せつめいが いらない。そして **ペアの なかみを べんきょうの ないように できる**ので、あそびながら ふくしゅうに なる（この アプリ らしい）。

### 流れ
1. カードが うらむきで ならぶ。2まい めくって **ペアなら とれる**、ちがえば もどる。
2. ぜんぶ とったら クリア。めくった かいすうが すくないほど ⭐ が おおい。
3. はじめの 2びょうだけ ぜんぶ おもてに する「ちらっと みせ」（Lv1〜3）。

### ペアの しゅるい（えらべる。はじめは「おなじ え」だけ）
| しゅるい | ペア | あたまの なか |
|---|---|---|
| おなじ え | 🍎 ↔ 🍎（①の くだもの） | きおく だけ |
| かず | 「5」 ↔ ●●●●● | さんすう |
| ひらがな・カタカナ | 「り」 ↔ 「リ」 | こくご |
| えいご | りんごの え ↔ **apple** | えいご（ABCぼうけんで ならった ことば だけ） |
| たしざん | 「2＋3」 ↔ 「5」 | さんすう（Lv6〜） |

### レベル
| Lv | まいすう（ペア） | ちらっと みせ |
|---|---|---|
| 1 | 6まい（3） | あり |
| 2〜3 | 8まい（4） | あり |
| 4〜5 | 12まい（6） | なし |
| 6〜8 | 16まい（8） | なし |
| 9〜10 | 20まい（10） | なし |

- ⭐3＝めくった かいすうが ペアの かず×1.5 いか、⭐2＝×2.5 いか、⭐1＝クリア。

> ほかの 案（③の かわり・あとで 足す）：**じゅんばん ひかり**（どうぶつの がっきたい が 音と ひかりで ならす → おなじ じゅんに タップ。1こずつ ながく なる）。耳の きおくも きたえられる。

## 4. ごほうび・きろく
- **⭐**：1もん せいかい ⭐1、1かい（5もん）ぜんぶ せいかい ⭐＋3、レベル アップ ⭐＋2。③は ⭐1〜3 ×2。`moko-math-v1` の `points` に 足すだけ。
- **1日の ⭐ の じょうげん**：⭐30（⚙️で かえられる。0 は なし）。じょうげんの あとも あそべる（⭐が でない だけ。「きょうの ⭐は もう いっぱい！」）。
- **ペットの ごはん**：学習履歴（`LH.recordAttempt`、subject `kioku`）に のこす → いまの ペットの しくみで ごはんに なる。
- **きょうの もくひょう**：入れない（べんきょうの 4つは そのまま）。
- **ごほうびの きせかえ**：3つの ゲーム ぜんぶ Lv10 で「ものしり メガネ」（あたらしい ITEM `a_kioku`。`grantItem()`）。
- **きろく**：ゲームごとの いまの レベル・さいこう レベル・あそんだ かいすう。タイトルに メーターで 見せる。
- **学習レポート**：subject `kioku`（「きおく」）を ひょうじに 足す。topic は `fruit`／`grid`／`pair`、`difficulty` に レベル。

## 5. 保存
`moko-math-v1` に 1こ 足すだけ（`defState()` に 初期値・`merge()` で 補う。保存キーは 足さない）：
```js
kioku: {
  fruit: { lv: 1, best: 1, plays: 0 },
  grid:  { lv: 1, best: 1, plays: 0 },
  pair:  { lv: 1, best: 1, plays: 0, kinds: ['same'] },
  day:   { d: '', pts: 0 },   // その日に もらった ⭐（じょうげん用）
}
```
設定は `settings.kiokuSpeed`（1.5／1／0.8）と `settings.kiokuDaily`（30）を 足す。

- **けっか**：⭐、レベルの メーター（あがった ときは ファンファーレ）、「もういちど」「ほかの ゲーム」。
