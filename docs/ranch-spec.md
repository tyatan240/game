# モコの ぼくじょう 仕様 v0.1

> 2026-11 作成。**まだ 実装しない**（決まったら Go）。
> まちに「ぼくじょう」を おくと、おうちで そだてた ペットが そこで くらす。あとから ぼくじょうの どうぶつ（うし・ひつじ・にわとり）も そだてられる。
> 「決めてほしいこと」（さいご）に 推奨案。

---

## 0. 方針
- **ペットの しくみは いまの まま**（`common/pet.js`・`moko-math-v1` の `S.pet`）。ぼくじょうは「そだてた ペットが くらす ばしょ」を まちに ふやす だけ。ペットや ごはんを まちで べつに もたない。
- **ごはんは べんきょうで もらう ものだけ**（いまの `S.pet.stock`）。ぼくじょう せんようの ごはんや おかねは つくらない。
- **よわらない・へらない**：おせわを しなくても げんきが なくなったり いなくなったり しない（`docs/daily-fun-spec.md` と おなじ）。「やると うれしい」で つくる。
- **⭐を ふやしすぎない**：ぼくじょうで とれた ものは ⭐に かえない。かざり・かぐ と こうかん する。
- 絵は コードで かく（ペットは いまの `petSVG`、ぼくじょうは まちの Canvas の え）。文字は ひらがな。

---

## 1. ぼくじょうを つくる
- まちの おみせ の「とくべつ」に **ぼくじょう**（さく で かこった 6×5 ＋ ちいさな こや）。⭐300（いまの パーツの なかで たかめ）。
- おきかたは いまの パーツと おなじ（つくる → ばしょを タップ → ここに おく。うごかす・けす も できる）。
- ぼくじょうの なかは ペットだけが あるく（じゅうにんは はいらない）。いりぐちの とびらが 1つ。

## 2. ペットの くらし
- そだてた ペット（`S.pet.pets`）が ぜんいん ぼくじょうに いる。たまごは いままでどおり おへやで あたためる。
- **うごき**：さくの なかを ゆっくり あるく・ときどき ねる・くさを たべる・ジャンプ。あたまの うえに なまえふだ（まちの いえと おなじ）。
- **タップ**で ペットの カード（おへやと おなじ）：
  - **なでる**：ハートが でて よろこぶ（1日1かい「なかよし ハート」が ふえる。下の 4.）。
  - **ごはん**：べんきょうで もらった ごはん（`stock`）を あげる。そだつ（おへやと おなじ しくみ）。
  - **おへやに つれていく**：おへやに でる ペットを えらぶ（いまは いちばん あたらしい ペット）。
- ぼくじょうの こやを タップ → 「ぼくじょう」の がめん：ペットの いちらん（そだち・なかよし）、とれた もの（3.）、こうかん。

## 3. ぼくじょうの どうぶつ（第2段階）
- ぼくじょうを おくと、つぎの たまごに **うし・ひつじ・にわとり** が でるように なる（いまの ねこ・とり・ドラゴンの こ に たす）。
- おとなに なると、**べんきょう した 日に 1かい** とれる：うし → ミルク（milk）、ひつじ → けいと（wool）、にわとり → たまご（egg）。
- とれた ものは「ぼくじょうの こや」で こうかん：
  - まちの かざり（ぼくじょう せんよう：かざぐるま・わらの やま・はなの さく・ミルクの スタンド）
  - おへやの かぐ（あたらしい `ITEMS`：ミルクの びん・ふわふわ クッション・たまごの ランプ など。id は あたらしく つくる）
- **英語**：どうぶつ・とれた ものの カードに 英語の なまえ（cow・sheep・hen・milk・wool・egg）と 🔊。えいごの へやと つながる。

## 4. なかよし（なでる）
- ペットごとに「なかよし ハート」。1日1かい なでると ＋1（なでなくても へらない）。
- 5・10・20 で ごほうび：ペットの リボン（みための かざり）・ぼくじょうの はた・とくべつな あいさつ。

## 5. 保存（ついかのみ）
- `moko-math-v1` の `S.pet` に たす（`core.js` の `defPet()` に しょきち、`merge()` で おぎなう）：
  ```js
  pet: {
    ...いまの こうもく,
    home: null,          // おへやに いる ペットの id（null＝いちばん あたらしい ペット。いまと おなじ）
    love: {},            // { ペットid: { n: なかよし, d: さいごに なでた 日 } }
    goods: { milk: 0, wool: 0, egg: 0 },  // とれた もの（第2段階）
    got: {},             // { ペットid: さいごに とれた 日 }（第2段階）
  }
  ```
- ぺっとの しゅるい（`PET_KINDS`）に cow・sheep・hen を たす（第2段階。いまの ペットの データは かわらない）。
- まち（`moko-town-v1`）は いまの `objects` に `type:'ranch'` が はいる だけ（パーツは `machi/js/data/parts.js` に 1ぎょう）。

## 6. まちとの つながり（つくりかた）
- まちの がめんで `common/pet.js` も よむ（いまは おへや だけ）。ペットの え（`petSVG`）を Canvas に えがく。
- ペットの うごきは まちの じゅうにん（`machi/js/town/people.js`）と おなじ しくみを つかい、あるける ばしょを ぼくじょうの なかに かぎる。
- ⭐は ぼくじょうを かう ときだけ つかう（`moko-math-v1` の `points`）。

## 7. 作る順番（案）
1. ぼくじょうの パーツ・ペットが くらす（あるく・なまえふだ）・タップで なでる／ごはん・おへやに つれていく ペットを えらぶ・なかよし ハート
2. ぼくじょうの どうぶつ（うし・ひつじ・にわとり）・とれた もの・こうかん（かざり・かぐ）・英語の なまえ
3. テスト（`tests/smoke.js`）・`sw.js`・docs
