> 置き場所（予定）：`dungeon/`（独立したフォルダ）。入口は おうちの「おべんきょう」画面（さんすう・こくご・えいご・プログラミング の となり）。

## 1. コンセプト
英語を覚えるほど冒険が上手になる、ターン制ダンジョンRPG（ローグライク）。
敵・アイテム・魔法・装備の名前を英語で表示し、タップすると日本語・絵・発音で確認できる。遊び方はローグライクを参考にするが、名前・キャラ・見た目・アイテム名は既存作品を真似しない（絵はすべてコードで描くオリジナル）。

## 3. 全体の流れ
- 最初の画面：「ぼうけんに いく」「つづきから（中断中）」「ずかん」「あそびかた」、最高到達階・クリア回数。
- ダンジョン：部屋と通路のランダムマップ。モコが1回動くと敵も1回動く。いつでも「おうちへ」で中断（1ターンごとに自動保存）。
- 5階ごと：ボス → 復習テスト5問（失敗しても進める）。
- 20階ボスでクリア：⭐と記念のきせかえ。
- 倒れたとき：「こんかい であった ことば」と最高到達階を表示して、次の挑戦へ。

## 4. チュートリアル（れんしゅうの へや）
小さな1階ぶんのマップで、ガイド役が1つずつ教える。できたら次へ（失敗しても やり直せる。倒れない）。
1. うごく：方向ボタン／行きたい マスを タップ
2. しらべる：落ちている **apple** を タップ → 詳細カード（英語・絵・「りんご」・発音・効果）
3. ひろう・つかう：apple を拾って食べる → HPが回復（英語と効果が つながる体験）
4. こうげき：れんしゅう用の **slime** に こうげき（弱い・反撃しない）
5. まほう：**magic book** を読むと **fire** を覚える → fire で たる／slime を こうげき（MPの説明）
6. そうび：**sword** を装備すると つよさが上がる
7. かいだん：**stairs** で次の階へ → 「ずかん」に ことばが のった ことを見せて おわり
- 初回は自動で始まる（とばせない）。2回目からは「ぼうけんに いく」を押すと「せつめいを みる／とばす」を選ぶ。

## 5. ステータス・戦闘
- HP・MP・レベル・つよさ・まもり（つよさ・まもりは装備で上がる）。MPは歩くと少しずつ回復。
- 1〜3階は負けにくい強さ。HPが減ると画面で知らせる。
- 敵ごとに動き方が違う（snake：近づいて こうげき／bat：ふらふら／angry pig：追いかける／ghost：壁を通る／dragon：遠くから）。

## 6. 英語の出し方・学習
- 学習対象（敵・アイテム・魔法・装備）は英語、メニュー・説明は日本語（ひらがな中心）。
- 何でもタップで詳細カード：英語名・絵・日本語・発音・効果・操作ボタン。
- 詳細カードを開かずに正しく使えたら「よめた」1回（「使った」と「覚えた」を区別する材料）。
- 2語の名前（angry pig・magic sword など）は11階から。英語だけのヒント（扉の key、宝箱の weak: fire など）を後半に少しずつ。
- 発音は ABCぼうけんと同じ音声合成（拾った・選んだ・魔法を使った とき。設定でオフ）。

### ことば（はじめの案・約45語）
- 敵 12：snake・bat・slime・rat・frog・spider・angry pig・ghost・bee・crab・wolf・dragon（ボス4体は特別な名前）
- アイテム 14：apple・bread・banana・meat・potion・key・torch・rope・magic book・treasure box・angel feather など
- 魔法 7：fire・water・ice・thunder・heal・light・wind（magic book で覚える）
- 装備 6：sword・shield・armor（11階からは magic sword・blue shield など）
- 形容詞 6（11階から）：angry・red・blue・big・little・magic

### 図鑑（ダンジョン専用）
Monsters / Items / Magic / Equipment。英語・日本語・絵・発音・出会った回数・使った回数・「よめた」回数・テストの正答率・関連する ことば。

## 7. 復習テストと ⭐
- 5階ごとに5問（英語→意味／意味→英語／絵→英語／発音→絵）。出会った ことばから、苦手を優先。
- 正解数に応じて ⭐ と「ことばの ちから」（次の5階のあいだ、つよさが少し上がる）。
- ⭐の目安：初めて着いた階 ⭐1、ボス初撃破 ⭐10、テスト 最大⭐5、図鑑10語ごと ⭐5、20階クリア ⭐30。`moko-math-v1` の `points` に足すだけ。
- 回答は学習履歴（`LH.recordAttempt`、subject 'eigo'）に記録して保護者レポートへ。

## 8. 作る順番

2. 広げる：6〜20階、残りの敵・魔法・装備、ボス4体、5階ごとのテスト、⭐連携、学習レポート
3. 仕上げ：2語の名前、英語だけのヒントの仕掛け、20階クリアの ごほうび

## 9. 保存（予定）
新しいキー（例：`moko-dungeon-v1`、localStorage＋IndexedDB）。中断中の冒険・最高到達階・クリア回数・図鑑・チュートリアル済みフラグ・設定。既存のキーは変えない（⭐ だけ `moko-math-v1` の points に足す）。
