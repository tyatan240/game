## 決定事項
| 項目 | 決定 |
|---|---|
| テーマ | あいさつ＋かず・いろ・かたち（会話・おみせ）と、ちいさな ぶん（I like ～ など） |
| ことばの あつかい | あいさつ・ことば・文は「おぼえた ことば／ぶん」として登録し、クエストで使う |

| 進め方 | ①エリア1〜2＋新しい遊び方 → ②エリア3〜4 → ③エリア5・タイトル選択・英語の部屋の問題 |

## ストーリー
こもじの もりの おくの もんを ぬけると「ことばの まち」。まちの みんなは 英語の「こえ」を なくして こまっている。
せんせいから ことばや ぶんを ならい、それを つかって まちの ひとを たすける。たすけるたびに まちに おと と いろが もどる。

## あたらしい あそびかた
- **ぶんカード**：まほうカードの はってん。ぶんの かたカード（I like ＿＿）に ことばカードを はめて ぶんを つくる → 音声で よむ → クエストが すすむ。ただしい ぶんは「おぼえた ぶん」に とうろく。
- **かいわクイズ**：キャラが 英語で はなしかける（音声＋もじ）→ へんじを ふきだしカードから えらぶ。
- **よむ もんだい**：英語（ふつうの かきかた）を よんで えを えらぶ／音を きいて もじを えらぶ／ぶんの カードを ならべる。

## データ・保存（予定）
- ことば：`data/words.js` に ワールド3の ことばを たす（`world:3`、`kind`：greet / number / color / shape / action / thing、`text`：ふつうの かきかた）。学習記録は いまと おなじ `S.records['w:id']`。
- ぶん：`data/sentences.js`（かた・つかえる ことば・音声・え）。`abc-adventure-v1` に `sentences:{}`（おぼえた ぶん）を **追加**（`state.js` の `load()` で おぎなう）。
- エリア：`data/areas/w3_*.js`、`areas.js` の AREAS・ORDER・CHAPTERS に たす。こもじの もりの みぎに でぐち（`needs:{flag:'lowerClear'}`）。
- クエスト：`data/quests.js` に たす（ぶんカード・かいわの ステップ `on:'sentence'`／`on:'talk3'` を ついか）。
- ★は おうちの ⭐へ（いまと おなじ）。ワールド3の きがえ（例：ことばの マント）。
- タイトル：ワールド2クリア後に「ワールド3から」（`world3State()`：ワールド1・2を おえた じょうたいを つくる）。
- 英語の部屋（`eigo/`）：ワールド3の もんだい（あいさつ・かず・いろ・ぶん）を ETYPES に たす（1回め③）。
- 新しい ファイルは `sw.js` の ASSETS に たし、CACHE を あげる。
