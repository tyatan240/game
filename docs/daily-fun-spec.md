# まいにち あそびたくなる しくみ 仕様 v0.1（実装まえ・たたき台）

> 2026-11 作成。**まだ実装しない**（Go が出てから着手）。
> 小学1年生が「きょうも ひらきたい」と思える しくみを、おうち（`index.html`）に足す。
> ① モコの ペット ② パパ・ママの はなまるスタンプ ③ まいにち 1ページの えほん。
> 下の「★ 決めてほしいこと」に推奨案を書いてあります。

---

## 0. ぜんたいの方針
- **やさしい しくみ**：休んでも なにかを うしなわない（ペットは 弱らない・えほんは 続きから）。「やらないと 損」ではなく「やると うれしい」で 毎日を つくる。
- **はじめの1問を かるく**：その日 1問でも といたら、ペットの ごはん・えほんの ページ が もらえる。
- **iPad の中だけ**で完結（外にデータを 送らない）。保存は `moko-math-v1` に 項目を 足すだけ（`defState()` と `merge()`）。
- 絵は すべて コードで描く（SVG）。文字は ひらがな中心。

## ① モコの ペット（おへやで そだてる）

### 流れ
1. **たまご**：はじめて「おべんきょう」を ひらいた日に、おへやに「なぞの たまご」が とどく（モコが「なにか とどいたよ！」）。
2. **あたためる**：勉強した日ごとに たまごが あたたまる（ゆらゆら・ひびが ふえる）。**3日**（連続でなくてよい）で かえる。
3. **かえる**：かえる演出（たまごが われて ペットが とびだす）→ 名前を つける（ひらがな 5文字まで。候補ボタン「ぴよ」「もふ」「ころ」も）。
4. **そだてる**：その日の勉強で「ごはん」が たまる → おへやで ペットを タップ → ごはん を あげる。ごはんの 数で そだつ。
   | すがた | 必要な ごはん（合計） | めやす |
   |---|---|---|
   | あかちゃん | 0 | かえった日 |
   | こども | 10 | 約1〜2週間 |
   | おとな | 30 | 約1か月 |
   | とくべつ（キラキラ） | 60 | 約2か月 |
5. **おとなに なるとき**、いちばん よく勉強した教科で すがたが かわる（4しゅるい）：
   | 多い教科 | すがたの とくちょう |
   |---|---|
   | さんすう | からだに 星と 数字の もよう |
   | こくご | ほんを もった はかせ風（めがね） |
   | えいご | ちいさな つばさ・ABC の リボン |
   | プログラミング | ロボの アンテナ・ひかる 目 |
6. おとなに なったら「ずかん」に のる。**つぎの たまご**が とどく（ペットは ずっと おへやに いる。最大 3びき まで おへやに出す。のこりは ずかんから えらぶ）。

### ごはん
- その日の 勉強 **5もんごと に 1こ**（1日 最大 3こ）。1問目で まず 1こ（はじめの ハードルを ひくく）。
- 「きょうの もくひょう」ぜんぶ たっせい で ボーナス 1こ。
- ごはんは その日の うちに あげなくても たまる（あげ忘れても なくならない）。

### きもち（やさしく）
- 毎日 会うと「うれしい」。2日 会わないと「さびしかったよ〜」と言って すりよる（**弱らない・いなくならない・へらない**）。
- タップすると しゃべる（日替わりの ひとこと。「きょうは なにを べんきょうする？」「7の だん すき！」など、その子の 勉強に あわせた ことばも）。
- ごはんを あげると ハートが でて ジャンプ。

### ペットの しゅるい（はじめの たまご）
- たまごの もようで 3しゅるい（ねこ・とり・ドラゴンの子）。どれが 出るかは かえるまで ひみつ。
- 2こ目以降の たまごは まだ そだてていない しゅるいが 優先。

### 画面
- おへや（`roomSVG`）の すみに ペット（または たまご）。タップで「ペットの へや」ポップアップ：すがた・名前・ごはんの 数・つぎの すがたまで の バー・「ごはんを あげる」ボタン。
- おうち画面の「きょうの もくひょう」の下に「🍙 ごはん ○こ もらえるよ（あと ○もん）」の ひとこと。

## ② パパ・ママの はなまるスタンプ と ひとこと

### おとな（パパ・ママ）が すること
1. ⚙️設定と同じ 保護者確認（かけ算）を とおる → 「はなまるを おくる」画面。
2. **だれから**：「パパ」「ママ」を えらぶ（名前は 設定で かえられる：例「おとうさん」「おばあちゃん」も 追加できる。最大 4人）。それぞれ 色が ちがう（パパ＝青、ママ＝ピンク など）。
3. **スタンプを えらぶ**（16しゅるい。下の表）。
4. **ひとこと**（なくても よい。ひらがな・かんじ OK。20文字まで。定型文ボタンも：「よく がんばったね！」「7の だん すごい！」「あしたも たのしみ！」「だいすき」）。
5. **どの日の 勉強に**：「きょう」か「きのう」。その日の 勉強の まとめ（何もん・どの教科）を 見ながら おせる。
6. 1日に 何こでも おせる（パパと ママ 両方から も OK）。

### スタンプの しゅるい（16しゅるい。すべて コードで描く）
| グループ | スタンプ |
|---|---|
| はなまる | はなまる（あか）・にじいろ はなまる・きんの はなまる |
| ことば | よくできました・がんばったね・すごい！・100てん・ありがとう |
| かお・きもち | にこにこ・ハート・ぎゅー（だきしめ）・グッド（おやゆび） |
| きせつ・とくべつ | ほし・トロフィー・王冠・おはな |
- だれから押したかで **ふちの色と小さな名前**が つく（パパ＝青いふち「パパ」、ママ＝ピンクの ふち「ママ」）。
- 特別な スタンプ（にじいろ・きん・王冠）は 子どもが 開くと キラキラ演出。

### 子どもが 見る
- 次に おうちを ひらくと、モコが「おてがみが とどいてるよ！」→ 封筒を タップ → スタンプが ポンと おされる演出 → ひとことを 読み上げ（音声）。
- 「はなまるノート」（カレンダー形式）：日ごとに もらった スタンプが ならぶ。月ごとに めくれる。パパ・ママ それぞれの 数も。
- もらった スタンプで ⭐ は ふやさない（ごほうびは「ほめられる うれしさ」そのもの。⭐で 買えない 特別感）。※ 決めてほしいこと 4

## ③ まいにち 1ページの えほん「モコの ものがたり」

### 流れ
- その日 **「きょうの もくひょう」を 1つ たっせい**すると、えほんの つぎの 1ページが ひらく（1日 1ページ。まとめて 読み進めは できない＝「つづきは あした」の ワクワク）。
- 1話 7ページ（1週間で 1話）。読み終わった 話は 本棚に ならび、いつでも 読みかえせる。
- ページは 絵（コードで描く場面）＋ ひらがなの 文（2〜3行）＋ 読み上げ（日本語の 音声合成。文を 1文ずつ 光らせる）。
- 最後の ページで「おしまい」＋ 次の話の 表紙の チラ見せ。話を 読み終わると ⭐5 と 本棚に シール。

### 話の 案（はじめの 6話。モコと なかまの 日常の 冒険）
1. **モコと なぞの たまご**（ペットと つながる：たまごが とどいて、なかまと 中身を 想像する）
2. **モコ、まちへ おつかい**（数を かぞえて 買いものする。さんすう）
3. **きえた ABC**（アルファベットが にげだす。えいご）
4. **ロボモコの まいご**（じゅんばんに 指示して 家に かえる。プログラミング）
5. **ゆきの ひの てがみ**（ひらがなの てがみを 書く。こくご／冬）
6. **モコの たんじょうび**（みんなで パーティー）
- 1話ごとに 勉強の教科と ゆるく つながる（読んだあと その教科に 行きたくなる）。季節の話（クリスマス・お正月）は その時期に 追加。

### 画面
- おうちに「📖 えほん」ボタン（今日の ページが 読めるとき は 光る・バッジ「NEW」）。
- 本棚：読み終わった 話の 表紙が ならぶ。読んでいる 話は「○ページめ まで」。

## 4. おうち画面での 見せ方（まとめ）
- おへや：ペット（たまご）が いる。手紙が とどいていると 封筒が ひかる。
- 「きょうの もくひょう」カードの 下に、きょう もらえる もの の 案内：
  「1もん とくと → 🍙ごはん・📖えほんの つづき」
- 1日の 最初に 開いたときの 順番：① おてがみ（あれば）→ ② ペットの あいさつ → いつもの おうち。

## 5. 保存（予定）
`moko-math-v1`（S）に 項目を 足すだけ：
```
pet:   { eggs:[{kind, warm, got}], pets:[{id, kind, name, food, stage, form, born}], foodToday:{day, got, given}, lastSeen, shown:[ids] }
notes: { senders:[{id:'papa', name:'パパ', color}], list:[{id, from, stamp, text, day, at, seen}] }
book:  { story, page, lastDay, done:[storyIds] }
```
- 「その日 勉強したか」は 今の `daily`（`dailyOf(S)`）と 学習履歴（`LH`）から 判断する（新しい 数え方は 作らない）。

## 6. 作る順番（案）
1. **② はなまるスタンプ**（いちばん 小さい・すぐ 効く）：保護者画面・スタンプ16・手紙の演出・はなまるノート
2. **① ペット**：たまご → かえる → ごはん → そだつ（あかちゃん・こども）→ おとなの 4すがた → 2こ目の たまご
3. **③ えほん**：しくみ（1日1ページ・本棚・読み上げ）＋ 1〜2話 → のこりの 話を 少しずつ 追加

## ★ 決めてほしいこと（推奨は太字）
1. **ペットの たまごが かえるまで** → **勉強した日 3日**（連続でなくてよい）／1日（すぐ かえる）／7日
2. **ペットが 弱ることは ある？** → **ない（さびしがるだけ）**／ごはんを あげないと 元気が へる（元気に もどる）
3. **スタンプを おせる 人** → **パパ・ママ（名前を かえられる・最大4人まで 追加）**／パパ・ママ の 2人だけ
4. **スタンプで ⭐ も ふやす？** → **ふやさない**（ほめられる うれしさを 大事に）／1こ ⭐1
5. **えほんの ページが ひらく 条件** → **もくひょう 1つ たっせい**／1問 とく／もくひょう ぜんぶ たっせい
6. **はじめに 作る もの** → **② → ① → ③ の 順**／3つ 同時に 少しずつ
