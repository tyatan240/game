## 0. ねらい・方針
- **もじの なまえ と もじの おと を わける**：A は「エイ」（なまえ）、でも apple の a は「ア」（おと）。
- **3だんかい**：① もじの おと → ② おとを つなげて よむ（c・a・t → cat）→ ③ おなじ かたちの なかま（cat・hat・bat）と、きいた ことばを もじで つくる。
- よむ ことばは **3もじの みじかい ことば**（子音＋母音＋子音。cat・dog・sun など）だけ。むずかしい つづり（ee・sh など）は さいごに すこしだけ。
- いままでの ワールドと おなじ あそびかた（あるく・せんせいに ならう・クエスト・もん）。あたらしい あそびは 3つ（下の 3.）。
- ローマ字とは まぜない。画面に「えいごの おと」と はっきり だす。

## 1. ストーリー
こもじの もりの みなみの ふなつきばから ふねで「おとの しま」へ。
しまの いきものたちは ことばの「おと」が ばらばらに なって、しゃべれなく なって いる（「キャ… ア… ト…」）。
せんせいに もじの おとを ならい、おとを つなげて ことばを もどして あげる。ことばが もどるたびに しまに うたと いろが もどる。

## 2. エリア（5つ）
| # | エリア | おと（もじ） | おもな あそび | クエスト例 |
|---|---|---|---|---|
| 1 | おとの はまべ | s・a・t・p・i・n | おとカード（もじ と おと と えの ことば）・はじめの おと | かにさんの おとしもの：s で はじまる ものを 3つ あつめる |
| 2 | ひびきの ほらあな | c(k)・e・h・r・m・d | おわりの おと・まんなかの おと | こだまが まねする おとを きいて、どの もじか こたえる |
| 3 | つなげの たにま | g・o・u・l・f・b | **つなげて よむ**（いしの ブロックの もじが ひかって おと → くっついて ことば → えを えらぶ） | はしの いしに かいた ことばを よんで、ただしい えの いしを おく |
| 4 | なかまの むら | j・z・w・v・y・x・qu | **なかまさがし**（-at・-og・-un・-ig・-en）・**おとで つくる**（きいた ことばを もじタイルで つくる） | おまつりの やたいの かんばんを つくる（hat・cat・bat の みせ） |
| 5 | おとの とう | おさらい（＋ sh・ch・th を すこし） | よんで えを えらぶ・きいて つくる | かいごとに ことばを よんで かねを ならす → さいごの おさらい → クリア |

- もじの じゅんばんは、はやく ことばが つくれる じゅん（s a t p i n だけで sat・pat・tin・pin・nap が よめる）。
- クリアの ごほうび：きせかえ「おとの ヘッドホン」（`items`、ワールド3の ことばの マントと おなじ しくみ）。

## 3. あたらしい あそびかた
- **おとカード**：もじ（大きく a）＋ おと（ア）＋ えの ことば（apple）。🔊で「ア… ア… apple」。せんせいが 1もじずつ おしえて、きく／えらぶ クイズ → `S.sounds` に とうろく（★＋1）。
- **つなげて よむ**：3つの もじタイルが じゅんに ひかって おとが なる（ク… ア… トゥ）→ タイルが くっついて ことば（cat）を よむ → えを 3つから えらぶ。じぶんで タイルを タップして なんども きける。
- **おとで つくる**：ことばを きく（いぬ の え ＋ 🔊 dog）→ もじタイルを じゅんに えらんで d・o・g を つくる。まちがえた もじは そっと もどる（ヒント：その おとを もう いちど）。
- **なかまさがし**：cat・hat・dog・bat から なかまで ない ものを えらぶ／おしりが おなじ ことばを あつめる。

## 4. ことば（よむ ことば・やく40）
- -at：cat・hat・bat・rat・mat ／ -an：can・fan・man・pan・van ／ -ap：cap・map
- -en：hen・pen・ten ／ -et：jet・net・wet ／ -ed：bed・red
- -ig：big・dig・pig・wig ／ -in：pin・tin・win ／ -ip：lip・zip
- -og：dog・log・fog ／ -ox：box・fox ／ -op：top・hop
- -un：bun・run・sun ／ -ug：bug・hug・mug ／ -up：cup・pup ／ -us：bus
- え：あるものは つかう（cat・dog・sun・red・fish など）。たりない ものは `engine/art4.js` に コードで かく（ぜんぶ SVG/Canvas）。
- ワールド1・3で であった ことば（cat・dog・sun・red・ten など）を わざと いれる（いみを しっている ことばが よめると うれしい）。

## 5. おと（こえ）の だしかた　※だいじ
iPad の よみあげ（speechSynthesis）は ことば は じょうずに よめるが、**もじ 1つの おと（/æ/・/b/ など）は うまく だせない**。
- **案A（推奨）**：
  - のばせる おと（s・m・n・f・l・r・v・z・sh）は のばした つづり（"sss"・"mmm"）で よませる。
  - とまる おと（b・c・d・g・p・t・k）と 母音は、**「その おとで はじまる ことば」を いっしょに**（"a… apple"・"b… bat"）。
  - つなげて よむ ときは、タイルを 1つずつ ひからせて ことばの さいしょから すこしずつ（"c"→"ca"→"cat" の ように よませる）。
  - あとから ろくおんを たせるように、`letters.js` の `audio`（いまは null）に ファイルを いれれば そちらを つかう（いまの `sayLetter()` と おなじ）。
- 案B：さいしょから 26おとの ろくおん ファイルを よういする（おとは いちばん きれい。ろくおんの てまが いる）。
- 案C：パパ・ママが ⚙️せってい で iPad に ろくおん できる ように する（いちばん しぜん。つくる りょうが ふえる）。

## 6. データ・保存（予定）
- `data/phonics.js`：おと（`id:'a'`・`say`（よませかた）・`key`（apple）・`group`（エリア））。
- `data/words.js` に ワールド4の ことば（`world:4`、`kind:'cvc'`、`fam:'at'` など）。
- エリア：`data/areas/w4*.js`（5つ）、`areas.js` の AREAS・ORDER・CHAPTERS に たす。こもじの もりの みなみに ふなつきば（`needs:{flag:'lowerClear'}`）。
- `abc-adventure-v1` に **たすだけ**：`sounds:[]`（おぼえた おと）・`w4clears:0`。`state.js` の `load()` で おぎなう。`knownOf()` に `sounds` を たす（「はじめから」でも きえない）。
- がくしゅう きろく（`records`）：おと `snd:a`・よむ `rd:cat`・つくる `sp:cat`。
- タイトル：ワールド2 クリア後に「ワールド4（おと）」（`world4State()`：ワールド1・2を おえた じょうたい。ワールド3は いらない）。ワールドごとの つづき は `S.slots[4]`。
- えいごの へや（`eigo/`）：ETYPES に「おとを きいて もじ」「つなげて よむ」「おとで つくる」を たす。きょうの ふくしゅう にも いれる。
- 保護者レポート：「おと（a〜z）」「よめる ことば」の かず・にがて。
- ★は おうちの ⭐へ（いまと おなじ）。新しい ファイルは `sw.js` の ASSETS・CACHE。
