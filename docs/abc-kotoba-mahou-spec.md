# ABCぼうけん 仕様書：「ことばの まほう」＋「ことばの くみあわせ」

対象：小学1年生 ／ 前提：`abc/` の MVP（ワールド1：A〜E）／ 状態：**第1〜5段階 実装済み**（HONEY は データの いれものだけ）

## 0. いちばん大事なこと
**英語を覚えること自体が、冒険を進める能力になる。**
クイズに正解して星を集めるだけにしない。覚えた英単語を「まほう」として使い、物を動かす・動物を助ける・植物を育てる・道を開く。
子どもが「じぶんの おぼえた えいごで せかいが かわった！」と感じられることを最優先する。

## 2. システム
### 2-1. ことばの まほう
- 英単語を覚えると、その単語の「まほう」が使えるようになる（例：APPLE＝りんごを収穫、WATER＝水を使う、FLOWER＝花のまほう、DOG＝犬と仲良く、KEY＝鍵や扉の仕掛け）。
- 覚えたときに **単語カード獲得の演出**。カードの表示：英単語／イラスト／日本語の意味／英語音声ボタン／習得状況。
- 覚えた単語は **「ことばずかん」** に登録（メニューから見られる。タップで発音）。

### 2-2. ことばの くみあわせ
- 覚えた単語 **2枚** を選んで使うと、新しい効果が出る。
- 例：WATER+FLOWER＝花を育てる、FLOWER+BEE＝ハチを呼ぶ、BEE+HONEY＝ハチミツを集める、SUN+FLOWER＝花を元気に、APPLE+BASKET＝りんごをかごに、KEY+DOOR＝扉を開ける。
- **順番は関係ない**（WATER+FLOWER と FLOWER+WATER は同じ）。
- 正しい組み合わせ → **ゲーム世界が実際に変わる**。短い日本語の説明とアニメーションつき。
- 間違い → ペナルティなし。ヒントを出す。
- 効果は **対象のオブジェクトとクエストの状態で決まる**。単語を覚えただけで、あちこちの仕掛けが勝手に動くことはない（その場所で組み合わせを使ったときだけ）。

## 3. クエスト
### 3-1. 第1クエスト「りんごを とどけよう！」
1. うさぎ（ラビ）から「りんごを もってきて」と頼まれる
2. りんごの木を探す
3. 木を調べると APPLE の学習イベント（英語音声＋絵）
4. 簡単なクイズで確認 → APPLE のまほうを習得
5. まほうで りんごを収穫 → 持ち物に りんご
6. ラビに届ける → お礼に **はしの かぎ**
7. かぎで **橋の門** を開ける → 次のエリアが解放

### 3-2. 第2クエスト「かれた はなばたけ」（今回の中心）
1. 橋の先で **枯れた花畑** を見つける
2. そばの動物「おはなが かれちゃった。たすけて！」→ 依頼を受ける
3. **井戸（または池）** で WATER の学習 → クイズ正解で WATER 習得
4. **花畑の看板** で FLOWER の学習 → クイズ正解で FLOWER 習得
5. 花畑を調べる →「ことばを くみあわせよう！」
6. WATER と FLOWER を選んで「まほうを つかう！」
7. 演出：2枚のカードが光る → 中央で合体 → 光の粒が花畑へ → 水が降る → 芽が出て成長 → 色鮮やかな花畑に → 動物が喜ぶ
8. 報酬をもらい、花畑の先の道が開く

### 3-3. 第3クエスト「ハチさんを よぼう」（組み合わせの再利用の確認）
1. 花は咲いたのにハチがいない →「ハチさんを よんでほしい」
2. BEE を学習
3. FLOWER＋BEE → 花畑にハチが飛んでくる
4. 報酬
- FLOWER を第2・第3クエストの両方で使い、自然に復習させる。
- 次の HONEY（BEE+HONEY）は **データの入れ物だけ用意**（実装は将来）。

## 4. 画面
### 4-1. くみあわせ画面（スマホ・iPad 優先）
- 上：「ことばを くみあわせよう！」／中央：選んだカード2枚の枠／下：覚えた単語カードの一覧
- 操作：カードをタップで選ぶ（2枚）→「まほうを つかう！」→ 結果。**タップだけで完結**（ドラッグ不要）。選んだカードをもう一度タップで外す。
- カードをタップすると英語音声。
- まだ覚えていない単語は「？」でよい。ただし **ヒントボタン** で「どこで覚えられるか」が分かるようにして、進行に必要な単語が探せなくならないようにする。

### 4-2. クエストの案内
- 画面上部に **いまの目的**（例：「いどを さがそう！」「WATERを おぼえよう！」「おはなの かんばんを さがそう！」「ことばを くみあわせよう！」「うさぎさんに ほうこくしよう！」）。進行に合わせて自動更新。
- 目的地に「！」の目印。目的地が画面外のときは、画面の端に **方向の矢印**。

## 5. データ（データ駆動・追加でロジックを書き換えない）
新しいファイル：`abc/js/data/words.js`・`combos.js`・`quests.js`

**単語**
```js
{ id:'water', word:'WATER', ja:'みず', art:'water', audio:null, speak:'water',
  learnAt:'well',            // 習得イベントが起きる場所（オブジェクトID）＝ヒントにも使う
  quiz:['picture','listen'] } // 確認クイズの形式（絵・音・文字）
```
習得状態はセーブデータ側に持つ（データ定義には持たない）。

**組み合わせ**
```js
{ id:'water+flower', words:['flower','water'],   // 順番は無視（並べ替えて比較）
  target:'flowerbed',                              // どこで使うと効くか
  when:{ quest:'flowers', step:'combine' },        // 発動条件（クエストの段階・対象の状態）
  effect:[ {set:'flowerbed', to:'bloom'}, {open:'path_east'}, {give:'star', n:2} ],
  fx:'rain-bloom',                                 // 演出の種類
  text:'みずで おはなが げんきに なった！',
  hint:'みずと おはなの まほうが いるみたい' }    // ちがう組み合わせの ときの ヒント
```
**クエスト**
```js
{ id:'flowers', title:'かれた はなばたけ', requires:'apple',
  steps:[ {id:'talk',    goal:'はなばたけの どうぶつに はなしかけよう！', target:'mole'},
          {id:'water',   goal:'いどを さがそう！',                 target:'well',      learn:'water'},
          {id:'flower',  goal:'おはなの かんばんを さがそう！',     target:'flowerSign',learn:'flower'},
          {id:'combine', goal:'ことばを くみあわせよう！',         target:'flowerbed'},
          {id:'report',  goal:'どうぶつに ほうこくしよう！',       target:'mole', reward:{star:3}} ] }
```
- 汎用の処理（目的表示・目印・学習イベント・組み合わせ判定・効果の適用）を1か所に作り、各クエストはデータで書く。
- 効果の種類（`set` マップ状態／`open` 道・門／`give` 持ち物・星／`spawn` キャラ出現／`advance` クエスト進行）を増やすときだけロジックを足す。

## 6. セーブデータ（`abc-adventure-v1` に項目を追加。互換を守る）
```js
words:    { water:{ at:時刻 } },        // 習得済み単語
records:  { 'A':{…}, 'w:water':{…} },   // 学習履歴（既存の文字記録と同じ形。単語は 'w:' を付ける）
combos:   ['water+flower'],             // 発見した組み合わせ
quests:   { apple:'done', flowers:'combine', bee:null }, // クエスト進行（学習状態とは別）
inv:      { apple:1, bridgeKey:1 },     // 持ち物（既存の items＝きがえ とは別）
world:    { flowerbed:'bloom', bees:true, gate:'open' }, // マップの変化
areas:    ['meadow','flowerfield']      // 解放済みエリア
```
- 既存の `learned`・`records`・`stars`・`flags`・`items`・`wear`・`settings` は名前も意味も変えない。
- 新項目は `state.js` の `defaultState()` に初期値を足し、`load()` で古いデータにも補う。

## 7. 学習の設計
- 初回正解 →「まほうが つかえる」（＝ゲームは進められる）。**「おぼえた」は後日の復習で上げる**（既存の習熟度：正解3回以上・連続2回以上・正解率70%以上）。
- 進めるために同じ問題を何度も解かせない。覚えた単語は別のクエストで使うことで自然に復習（FLOWER は第2・第3クエスト両方）。
- 問題は絵・音・文字を組み合わせ、1年生に分かる難しさ（例：音を聞いて絵を選ぶ／絵を見て単語を選ぶ、3択から）。
- 単語の発音は既存の音声合成（`speak`）、録音ファイルがあれば `audio` を優先。

## 8. 技術要件
- 既存の `abc/` のコード（移動・会話・クイズ・学習記録・音声・セーブ）を流用。HTML5/CSS/JS、外部ライブラリなし、GitHub Pages、バックエンドなし。
- スマホ・iPad（タップのみで完結）。オフライン動作を考慮。

## 11-2. 実装メモ（どこに何があるか）

- 旧MVPのセーブ（門の向こうにいた場合）は、続きから始めると門の手前に戻る。
