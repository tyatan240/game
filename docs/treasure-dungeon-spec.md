# モコの たからさがしダンジョン 仕様 v0.4

> 2026-11 作成。Go 済み。**第1段階「基本」・第2段階「かくし部屋」実装済み**（下の 12. 13. 実装メモ）。第3段階（仕上げ・カードガチャ）は まだ。
> v0.2：決めてほしいことを決定（下の「決まったこと」）。ダブりの かけらは「かけらの カードガチャ」専用に変更（3-4）。
> イングリッシュダンジョン（`docs/dungeon-spec.md`）を20階までクリアすると遊べる、もっと難しい「たからさがし」モード。
> 宝物は **A〜Z の頭文字のアイテムカード**（1文字につき3まい、全78まい）。カードを集めて「カードずかん（アルバム）」を完成させる。
> 下の「★ 決めてほしいこと」に推奨案を書いてあります。

---

## 1. コンセプト
- イングリッシュダンジョンと同じ遊び方（ターン制・ローグライク・英語の名前）。目的は「階段を降りること」から「**宝物を見つけること**」に変わる。
- 宝物は **カード**。A〜Z のそれぞれの文字から始まる英単語のカードを集める。
  - 例：A … apple（★）・anchor（★★）・angel（★★★ キラ）
- 集めたくなる しかけ（トレーディングカードの楽しさ）を取り入れる。ただし既存作品の名前・絵・デザインは真似しない。カードの絵・枠はすべてコードで描く。
  - レア度とキラ
  - 開けるときの ドキドキ演出
  - カード番号
  - アルバム
  - コンプリートのごほうび
- 英語の学習につなげる。
  - カードを手に入れたとき：文字と単語の読み上げ（「A, apple!」）。
  - かくし部屋の とびら：英語のクイズになっている。

## 2. はじめかた
- イングリッシュダンジョンのタイトル画面に「たからさがし」ボタンを足す。
  - 20階クリア前は かぎマーク付きで「20かいを クリアすると あそべるよ」と表示する。
  - 管理者モードでは最初から遊べる。
- 1回の冒険は 1〜20階。
- 中断・つづきから はイングリッシュダンジョンと同じ。冒険は別々に1つずつ持てる（英語ダンジョンの途中データは消えない）。

## 3. カード（全78まい）

### 3-1. レア度
| レア | しるし | 枠・見た目 | ねらい |
|---|---|---|---|
| ふつう | ★ | 白い枠 | 文字ごとの いちばん かんたんな ことば |
| レア | ★★ | 銀の枠・すこし光る | すこし むずかしい ことば |
| キラ | ★★★ | 金の枠＋虹色に光る（傾けると光が動く） | 「たからもの」らしい ことば |

- カードの表示内容
  - 番号（例：`No.001 / 078`、A★＝1、A★★＝2、A★★★＝3 … Z★★★＝78）
  - 大きな頭文字
  - 英単語（頭文字だけ色を変える）
  - 絵、日本語の意味
  - 🔊（読み上げ）
  - みじかい例文（例：`This is an apple.`）
- キラカードの光
  - 指でなぞる、または iPad を傾けると光が動く。
  - 傾きが取れない環境では、ゆっくり光が流れる表示にする。

### 3-3. 集めたくなる しかけ
- **カードを あける演出**
  1. 宝物を見つけると、カードが裏向きで出てくる。
  2. 裏の光る色でレアが少し分かる。白＝★、銀＝★★、金と虹＝★★★。
  3. タップでくるっと めくれる。
  4. 「A, apple!」と読み上げる。
  5. 初めてのカードには「NEW!」が付く。
- **アルバム（カードずかん）**
  - A〜Z のページをめくる形にする。
  - 1ページに1文字、3まいの枠がある。持っていない枠は「？」と、うすい頭文字だけ表示する。
  - 何まい持っているか（ダブり）は小さく表示する。
- **コンプリート**
  - 1文字の3まいがそろうと、その文字の「もじバッジ」がもらえる。アルバムの そのページが光る。
  - 78まい全部そろうと「たからさがし マスター」。記念のきせかえ（おうちの ITEMS に新しい id を足して `grantItem`）がもらえる。
- **ダブり → かけら**
  - 持っているカードがまた出たら「きらきらの かけら」になる。★＝1こ、★★＝3こ、★★★＝10こ。
  - かけらは **「かけらの カードガチャ」専用**（3-4）。交換所は作らない。
- **出やすさの工夫**（ダンジョンでも ガチャでも おなじ）
  - 同じレアの中では、まだ持っていないカードが少し出やすい（約6割）。
  - 1回の冒険で、少なくとも1まいは「NEW!」が出るように調整する。

### 3-4. かけらの カードガチャ
- タイトルの「カードガチャ」。かけら **10こで 1回**（かけら専用。おうちの ⭐ では回せない。おうちの ガチャとは別もの）。
- 出るのは カード1まい。

  | ★ | ★★ | ★★★ |
  |---|---|---|
  | 70% | 25% | 5% |

  - まだ持っていないカードが少し出やすい（同じレアの中で約6割）。
  - **10回ごとに ★★ 以上が かならず出る**。何回目かは画面に「あと 3回で ★★いじょう かくてい！」のように出す。
- ガチャでダブったときも かけらになる（ダンジョンと同じ数）。
- 演出は ダンジョンでカードを手に入れたときと同じ（裏向き → 光の色 → タップでめくる → 読み上げ → NEW!）。
- ガチャをまわす前に、かけらの数と「あと何こで1回」を見せる。

## 4. 宝物の手に入れかた（毎回ちがう場所・中身）
| 手に入れかた | 中身 | メモ |
|---|---|---|
| **宝箱（key で あける）** | カード1まい（ときどき2まい）＋アイテム | 1階に0〜2こ。key も同じ階のどこかにある |
| **かくし部屋** | カード1〜2まい（レアが1段階 出やすい） | 1階に0〜2こ（深いほど多い）。5. のクイズで入る |
| **ボス（5・10・15・20階）** | ★★ 以上が かならず1まい | 20階のボスは ★★★ が出やすい |
| **かくしボス** | ★★★（まだ持っていない文字を優先） | 11階から。6. の条件で出会える |
| **ゆかに落ちている** | まれに ★ カード | 宝箱にかぎらず探すたのしさ |

**深さとレア（めやす）**

| 階 | ★ | ★★ | ★★★ |
|---|---|---|---|
| 1〜5 | 85% | 14% | 1% |
| 6〜10 | 70% | 25% | 5% |
| 11〜15 | 55% | 33% | 12% |
| 16〜20 | 40% | 40% | 20% |

- かくし部屋は1段階深い階の確率で出る。
- 1回の冒険で8〜12まいくらい手に入る。全部そろうまで およそ20〜30回の冒険（かけらの ガチャを含む）を めやすにする。

## 5. かくし部屋（クイズで あける）
- 新しいコマンド「**しらべる**」を足す。
  - 行動ボタンに追加する。「まつ」と同じ大きさで、虫めがねの絵（コードで描く）を付ける。
  - 向いている方向の となりのマス（かべ・ゆか・看板）を調べる。1ターン使う。
- かくし部屋は、通路から1マスの「かくしかべ」の向こうにある。
  - 地図生成で、普通の部屋とは別の小部屋として作る。
  - 階段への道には関係させない。かくし部屋に入らなくてもクリアできる。
- 怪しいところには小さな手がかりがある。
  - かべの ひび
  - 光る文字
  - 色のついた たいまつ
  - 床の看板
- 手がかりを「しらべる」と、とびらのクイズが出る。正解すると かべが開いて入れる。

**とびらの クイズ（深いほど むずかしく）**
| 種類 | 出かた | 階 |
|---|---|---|
| ことばの とびら | とびらの絵 → 英単語を選ぶ（3択・読み上げ付き） | 1〜 |
| もじの とびら | 絵と `_at` → 足りない文字を選ぶ（c / h / b） | 1〜 |
| ならべかえ | 文字のパネル（K・E・Y）を ならべて単語にする | 6〜 |
| えいごの なぞなぞ | `It is red. It is round. It is a fruit.` を読み上げ → 絵から選ぶ | 11〜 |
| えいごだけの ヒント | 床の看板 `Look at the BLUE torch.` → その階にある色つき たいまつ（赤・青・黄）の正しい1つを「しらべる」 | 11〜 |
| もじあつめ | その階に散らばった文字タイル（S・T・A・R）を全部ひろって とびらで並べる | 16〜 |

- **まちがえたとき**：その とびらは5ターン閉じる（何度でも挑戦できる。罰はこれだけ）。
- 回答は学習履歴に記録する（subject `eigo`、topic `treasure`）。
- 英語だけのヒントは、イングリッシュダンジョン第3回の「英語だけのヒント」と同じしくみで作り、両方で使う。

## 6. かくしボス
- 出かた：11階から。かくし部屋の中で、まれに「きんの かぎ（gold key）」が見つかる。
  - きんの かぎを持って その階の「なぞの とびら」（金色の模様のかべ）を しらべる → かくしボスの部屋。
- かくしボスの案：treasure dragon（たからの ドラゴン）・crystal golem（すいしょうの ゴーレム）・shadow king（かげの おう）。どれもコードで描く オリジナル。
  - ふつうのボスより強い。弱点の魔法がある（説明カードに `weak: ice` と英語だけで書く）。
- 倒すと ★★★ が かならず1まい（まだ持っていない文字を優先）。
- 1回の冒険で最大1体。

## 7. むずかしさ（イングリッシュダンジョンより難しく）
- 敵は同じ14種＋ボス。強さは「イングリッシュダンジョンの +5階ぶん」から始める（1階でも6階くらいの強さ）。
- 2語の名前の強い敵を足す（第3回と共通）：big slime・angry wolf・red dragon など。
- 弱い敵には、かくし部屋の近くを見まもる「見はり」の役も持たせる。
- わな（11階から）：落とし穴（1階下へ落ちる）・ねむりの床（1ターン動けない）。どれも「しらべる」で見つけられる。
- スタート時の持ち物：sword・apple 2こ・magic book 1さつ。モコは Lv1 から始まる（ローグライク）。
- 倒れたとき：その冒険で手に入れた**カードは なくならない**（決定）。持ち物・レベルは なくなる。

- **ダンジョン**：イングリッシュダンジョンと同じ。

- **カードガチャ**：かけらの数・「10こで 1回」・確定までの回数・まわすボタン（3-4）。

## 10. 保存（予定）
- 新しいキーは作らず、`moko-dungeon-v1` に **項目を足すだけ**。英語ダンジョンのデータは変えない。
  ```
  treasure: {
    runs, best, clears,            // 冒険の回数・最高到達階・クリア回数
    cards: { 'A1': { n, first, seenNew }, ... },  // 持っているカード（n=まい数）
    shards,                        // きらきらの かけら（カードガチャ専用）
    gacha: { pulls, pity },        // ガチャを まわした かず・★★確定までの カウント
    badges: ['A', ...],            // もじバッジ
    rewarded: { ... },             // もらった ⭐ の記録
    run                            // 中断中の たからさがし（英語ダンジョンの run とは別）
  }
  ```
- `merge()` で `treasure` が無いときは初期値で補う。
- カード id は `文字＋レア`（`A1`〜`Z3`）で固定する。単語を差し替えても id は変えない。

## 決まったこと（2026-11）
1. 倒れたとき、その冒険で見つけたカードは **残す**。
2. 1文字の3まいは **3つの別の単語**（★→★★→★★★）。
3. ダブりは かけらになり、**かけら専用の カードガチャ**で使う（交換所は作らない）。
4. 始めの強さは **Lv1 から＋スタートの持ち物あり**（推奨どおり）。
5. ことばの一覧（3-2）は **このまま**（推奨どおり。あとから差し替え可。カード id は変えない）。
6. ⭐の量（9.）は **このまま**（推奨どおり）。

## 12. 実装メモ（第1段階「基本」）
- ファイル：`dungeon/js/cards.js`（カード78まい・レアの確率・かけら・⭐）、`dungeon/js/cardart.js`（カードの絵。apple・cat・dog・fish・flower・key・milk は ABCぼうけんの絵を使う）、`dungeon/js/treasure.js`（カードを もらう・めくる えんしゅつ・アルバム・メニュー）。ゲームの きまりは `game.js` の `run.mode === 'treasure'`。
- 入口：英語ダンジョンのタイトルの「たからさがし」（`D.rewarded.clear` か `D.clears > 0`、または管理者モード）。メニュー：つづきから／ぼうけんに いく／カードずかん。
- 中断：`D.treasure.run`（英語ダンジョンの `D.run` とは別。両方 同時に途中で おいておける）。
- 強さ：てき・アイテム・魔法の階は「1階＋1、2階＋2 … 5階から＋5」（`ef()`。最初から＋5 だと1〜4階で半分が倒れたため、少しずつ強くした）。ボスは HP ×1.3・こうげき ＋2。
  - 自動プレイ（アイテムを拾い、魔法を使う bot）で 20階クリア 約25%（英語ダンジョンは約60%）。1〜3階で倒れるのは数%。
- スタートの持ち物：sword（装備）・apple 2こ・magic book。
- 宝物（第1段階の確率）：
  - 宝箱：1階に 0〜2こ（60%で1こ＋20%でもう1こ）。中身は アイテム1こ＋ 55%で カード（10%は2まい）。
  - 床の カード（`tcard`）：1階に 20%。★が出やすい（1段 浅い階の確率）。
  - ボス：★★（10階から25%・20階は50%で ★★★、5階は10%）。
- カードを もらうと すぐ保存（倒れても残る）。新しい カードは ⭐（★1・★★3・★★★10）、3まい そろうと もじバッジ ⭐5、ダブりは かけら（★1・★★3・★★★10こ）。78まい そろうと ⭐100（記念きせかえは第3段階）。
- めくる えんしゅつ：裏の光（★ 白・★★ 青白・★★★ 金と虹）→ タップで めくる → 「A, apple!」の読み上げ → NEW!／かけら／もじバッジ。続けて もらったときは「つぎの カード」。
- カードの見た目：★ 白い枠、★★ 銀の枠＋光が流れる、★★★ 金の枠＋虹色（なぞると光が動く）。
- アルバム：A〜Z の ボタン と ◀▶ でページを めくる。持っていない枠は「？」。カードを タップすると大きく表示（例文「This is an apple.」の読み上げ）。
- まだのもの：かくし部屋・しらべる・クイズ（第2段階）、かくしボス・わな・カードガチャ・記念きせかえ（第3段階）。

## 13. 実装メモ（第2段階「かくし部屋」＋ レアカードの見た目）
- **レアカードの背景**（遊んでもらった後の要望）：縁だけでなく背景も光らせる。
  - ★★：銀色の背景に、光のすじ（ゆっくり回る）＋細かい きらめき＋ほし4つ が またたく。絵のまわりが青白く光る。
  - ★★★：虹色の背景が流れる＋金の光のすじ（回る）＋金と白の きらめき＋ほし8つ。絵が金色に光り、名前は虹色の文字。カードのまわりも金色に光る。
- **しらべる**：たからさがしでは行動ボタンの「まつ」が「しらべる」になる（何も見つからなければ1ターン休むので「まつ」の代わりになる）。キーボードは f。
  - 向いている方向（なければ となり）の あやしい かべ → とびらの クイズ。近くに あやしい かべがあると「この ちかくの かべが あやしい…」と教える。
- **かくし部屋**（`game.js` の `placeSecrets`・`openSecret`・`failSecret`）
  - ボスの階以外で 1階に 0〜2こ（1〜5階 0.7こ・6〜10階 1こ・11階〜 1.4こ くらい）。3×3 か 4×3 の小部屋を かべの中に予約し、通路・部屋の となりの かべ1マスが いりぐち。開くまでは ただの かべ（階段への道には関係しない）。
  - いりぐちの かべには ひび と ときどき光る ほし。初めて見えたとき「あやしい かべ（ひび）を みつけた！ となりで「しらべる」」と出す。
  - 正解：かべが開いて部屋に入れる。中に カード1まい（30%で2まい。1段 深い階のレア）＋60%で アイテム。⭐1。

## 14. その次の修正
- **★★★ を もっと豪華に**：濃い虹色の背景（流れる）＋ 金の光のすじ と 逆回りの ピンク・水色の光のすじ ＋ ふわふわ光る玉 ＋ 大小14この またたく星 ＋ 内側の金の縁どり ＋ 下に光る「★ キラカード ★」のリボン。★★ には銀の「レア」リボン。
- **背景の大きな文字**：絵の うしろに 大きく（縁どり付きで見える）。絵は文字の上に描くので じゃまに ならない。
- **めくったあとの「🔊 きく」**：「A, apple!」を何回でも聞ける。
- **宝箱と鍵**：階を作るときは かならず 宝箱と同じ数の鍵を置く（確認済み）。見つけにくい ことがあったので次の手当て。
  - 階に着いたとき「この かいには treasure box が 2こ、key も 2こ あるよ」と表示。
  - 鍵なしで宝箱に ぶつかると「この かいに key が あと ○こ あるよ」。
  - 鍵は ふくろ（ほん・どうぐ）が いっぱいでも 拾える。
