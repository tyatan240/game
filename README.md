# ゲームの へや

子ども向けの小さな Web ゲーム集です。サーバー側の処理はなく、ファイルを置くだけで動きます。

## 中身
| フォルダ | ゲーム |
|---|---|
| `index.html` | トップページ（ゲームを えらぶ） |
| `sansu/` | モコの さんすうハウス（たし算・ひき算で ⭐ を集めて着せかえ・部屋づくり） |
| `program/` | ピコの プログラミング（矢印・くりかえしブロックでロボットを動かすパズル、全12ステージ） |

各ゲームのフォルダには次のファイルがあり、それぞれ独立して動きます。
- `index.html` … ゲーム本体（これ1つでも動きます）
- `manifest.json` / `icon-*.png` … ホーム画面に追加したときの名前とアイコン
- `sw.js` … オフラインで遊べるようにするキャッシュ（https で公開したときだけ有効。そのフォルダの中だけが対象）

## 公開のしかた（GitHub Pages・無料）
1. このリポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
2. 数分後に次の URL で開けます
   - トップ: `https://<ユーザー名>.github.io/game/`
   - さんすうハウス: `https://<ユーザー名>.github.io/game/sansu/`
   - プログラミング: `https://<ユーザー名>.github.io/game/program/`

## iPad / Android で使う
1. 各ゲームの URL を Safari（Android は Chrome）で開く
2. 共有ボタン →「ホーム画面に追加」（ゲームごとに別のアイコンになります）
3. 以後はアイコンから起動。一度開けばオフラインでも遊べます

## データについて
- 進み具合は**その端末のブラウザ内**に保存されます（端末間で自動同期はしません）
- 保存キーはゲームごとに別です（さんすう: `moko-math-v1` / プログラミング: `piko-prog-v1`）
- iPad の Safari は、ホーム画面に追加せずにタブで使っていると、しばらく使わないとデータが消えることがあります。**ホーム画面に追加して使ってください**
- さんすうハウスの端末移行・バックアップは、⚙️設定 →「データの ひきつぎ」でコードを作り、移し先に貼り付けます
- さんすうハウスの設定画面は、右上の ⚙️ → かけ算（例: 7×8）に答えると開きます（保護者用）

## 更新するとき
ゲームの `index.html` を書き換えたら、同じフォルダの `sw.js` の `CACHE='…-v1'` の数字を上げると、
端末側で確実に新しい版に切り替わります。

## 新しいゲームを足すとき
1. 新しいフォルダ（例: `tokei/`）を作り、`index.html`・`manifest.json`・アイコン・`sw.js` を置く
2. `sw.js` の `CACHE` 名と、`localStorage` の保存キーは他のゲームと重ならない名前にする
3. トップの `index.html` にリンクを足す
