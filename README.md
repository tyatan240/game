# モコの おべんきょうハウス

> 開発者向けの要点は `CLAUDE.md`、詳しい仕様は `docs/`（構成・セーブデータ・開発ガイド）。動作確認は `node tests/smoke.js`。

子ども向けの小さな学習アプリです。サーバー側の処理はなく、ファイルを置くだけで動きます。
さんすう・こくご・プログラミングで ⭐ポイントをため、おうちの「おみせ」で着せかえや家具と交換します。

## 中身
| 場所 | 内容 |
|---|---|
| `index.html` | おうち（トップ）：おへや・おべんきょう（各部屋への入口）・🎰ガチャ・おみせ・きせかえ・⚙️設定 |
| `sansu/` | さんすう：たし算・ひき算、🏆テスト（合格で限定アイテム） |
| `kokugo/` | こくご：かん字の読み・書き（1年／2年）、ことば・ぶん、よみとり、🏆テスト（合格で限定アイテム） |
| `program/` | プログラミング：矢印・くりかえしブロックでロボットを動かすパズル（全12ステージ） |
| `abc/` | ABCぼうけん：英語（アルファベット）を覚える 2D アドベンチャー（独立モジュール・開発中。詳しくは `abc/README.md`） |
| `common/core.js` | 共通の処理：保存データ・ポイント・アイテム・キャラと部屋の絵・音・ポップアップ |
| `common/style.css` | 共通の見た目 |
| `manifest.json` / `icon-*.png` | ホーム画面に追加したときの名前とアイコン（アプリは1つ） |
| `sw.js` | オフラインで遊べるようにするキャッシュ（全部屋ぶん） |
| `sansu/sw.js` / `program/sw.js` | 以前の版で部屋ごとに入っていたキャッシュを片付けるためのファイル。消さずに残してください |

## 🏆 テスト（さんすう・こくご共通のルール）
- 問題の種類ごとに テスト1〜3（10問・15問・20問）。前のテストに合格すると次が開きます
- 時間内に合格すると、そのテストでしかもらえないアイテムがもらえます（さんすう18種・こくご18種）
- 「れんしゅう」はいつでもでき、ポイントが ⚙️設定の倍率ぶん増えます
- 制限時間は ⚙️設定の「テストの せいげんじかん」（ゆっくり／ふつう／きびしい）で両方まとめて変わります

## ポイントのしくみ
- ポイント・持ち物・設定は、全部屋で共通の1つのデータ（ブラウザの `localStorage` の `moko-math-v1`）に保存されます
- もらえるポイントは ⚙️設定 で変えられます
  - さんすう・こくご：問題の種類ごとのポイント、全問正解ボーナス
  - プログラミング：ステージで初めて取った ★1つあたりのポイント
  - ログインボーナス（1日1回、おうちを開いたとき）
- プログラミングのステージの進み具合は `piko-prog-v1` に別に保存されます

## 🎰 ガチャ
- ⭐100（設定で変更可）で1回。1/10の確率で ✨ちょうレア✨（12種）、それ以外は ふつう（20種）から1つ
- ガチャのアイテムは おみせでは買えません。持っているものが出たら ⭐10 になります
- ⚙️設定で、ガチャのオン・オフ、1回のポイント、1日に回せる回数（0＝制限なし）を変えられます
- アイテムを足すときは `common/core.js` の `ITEMS` に `gacha:'sr'` か `gacha:'n'` を付けて追加し、絵（`CH`・`OUTFIT`・`HAT`・`ACC`・`WALLX`・`FLOORX`・`FURN`）を描きます。家具は `roomSVG` の並び順にも足します

## ⚠️ 保存データを守るためのルール（更新するときは必ず守る）
アプリを更新しても、子どもがためたポイントや持ち物が消えないようにするための決まりです。

1. **保存場所の名前を変えない**：`localStorage` の `moko-math-v1`、IndexedDB の `moko-house`（中の `kv`）、プログラミングの `piko-prog-v1`
2. **データの形は「足す」だけ**：項目の名前を変えたり消したりしない。新しい項目は `defState()` に初期値を足し、`merge()` で古いデータにも補うようにする
3. **アイテムの `id` を変えない・消さない**：`merge()` は知らない `id` を持ち物から外すため、`id` を変えると持っていたアイテムが消える
4. **公開URLを変えない**：`https://tyatan240.github.io/game/` のまま（リポジトリ名や GitHub Pages の設定を変えると、別の保存場所になる）
5. **リセット処理を勝手に足さない**：データを消す処理は ⚙️設定の「データを リセット」だけ
6. **更新したら `sw.js` の `CACHE` の数字を上げる**（オフライン用の古いファイルを入れ替えるため。保存データには影響しない）
7. 大きく変えるときは、古いデータ（⚙️設定の「データの ひきつぎ」で作ったコードなど）を読み込んで、ポイントと持ち物が残ることを確かめてから公開する

## 公開のしかた（GitHub Pages・無料）
1. このリポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
2. 数分後に `https://<ユーザー名>.github.io/game/` で開けます

## iPad / Android で使う
1. 公開した URL（トップ）を Safari（Android は Chrome）で開く
2. 共有ボタン →「ホーム画面に追加」
3. 以後はアイコンから起動。一度開けばオフラインでも遊べます

## データについて
- データは**その端末のブラウザ内**に保存されます（端末間で自動同期はしません）
- iPad の Safari は、ホーム画面に追加せずにタブで使っていると、しばらく使わないとデータが消えることがあります。**ホーム画面に追加して使ってください**
- 端末の移行やバックアップは、⚙️設定 →「データの ひきつぎ」でコードを作り、移し先に貼り付けます
- 設定画面は、おうちの右上の ⚙️ → かけ算（例: 7×8）に答えると開きます（保護者用）

## 更新するとき
ファイルを書き換えたら、`sw.js` の `CACHE='moko-house-v1'` の数字を上げてください。
端末側で、オフライン用のキャッシュが確実に新しい版に入れ替わります。
（ページそのものは、ネットにつながっていれば開くたびに最新を取りに行きます）

## 部屋を足すとき
1. 新しいフォルダ（例: `tokei/`）を作り、`index.html` を置く
   - `kokugo/index.html` をひな形にすると、共通のポイントや見た目がそのまま使えます
2. `sw.js` の `ASSETS` にそのフォルダを足し、`CACHE` の数字を上げる
3. おうち（`index.html`）の `study()` に入口を足す
4. 問題の種類やポイントを設定画面で変えたい場合は、`common/core.js` の種類一覧と保存データの初期値（`defState`）に足す
