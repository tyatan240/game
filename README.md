# モコのさんすうハウス（単体版）

Claude がなくても動く、ふつうの Web アプリです。サーバー側の処理はなく、
このフォルダのファイルを置くだけで動きます。

## ファイル
- `index.html` … ゲーム本体（これ1つでも動きます）
- `manifest.json` / `icon-*.png` … ホーム画面に追加したときの名前とアイコン
- `sw.js` … オフラインで遊べるようにするキャッシュ（https で公開したときだけ有効）

## 公開のしかた（GitHub Pages・無料）
1. GitHub で新しいリポジトリを作る（例: `moko-math`。Public）
2. このフォルダの中身をそのままアップロード（Add file → Upload files）
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/moko-math/` で開けます

Netlify Drop（https://app.netlify.com/drop）にフォルダをドラッグしても公開できます。

## iPad / Android で使う
1. 公開した URL を Safari（Android は Chrome）で開く
2. 共有ボタン →「ホーム画面に追加」
3. 以後はアイコンから起動。一度開けばオフラインでも遊べます

## データについて
- ポイント・アイテム・設定は**その端末のブラウザ内**に保存されます（端末間で自動同期はしません）
- iPad の Safari は、ホーム画面に追加せずにタブで使っていると、しばらく使わないとデータが消えることがあります。**ホーム画面に追加して使ってください**
- 端末を移すときやバックアップは、⚙️設定 →「データの ひきつぎ」でコードを作り、移し先に貼り付けます

## 更新するとき
`index.html` を書き換えたら、`sw.js` の `CACHE='moko-math-v1'` の数字を上げてからアップロードすると、
端末側で確実に新しい版に切り替わります。

## 設定画面の開き方
右上の ⚙️ → かけ算（例: 7×8）に答えると開きます（保護者用）。
