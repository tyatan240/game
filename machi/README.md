# モコの まち（`machi/`）

おべんきょうで集めた ⭐ で まちづくりパーツを買って、2D の まちを自由に作る。ガチャなどで手に入れたキャラを家に住ませると、まちを歩く。
設計書：「モコのまちづくり ゲーム設計書 v1.1」（フェーズ1〜5を実装）。

## 入口・出口
- おうちの「おへや」の **ドア**（`index.html` の `home()`、`.todoor`）→ `machi/index.html`
- まちの **モコの おうち** をタップ → 「おへやへ」、または下の「🏠 おへや」→ `../index.html`

## 構成
```
index.html / style.css       画面（上：まちの名前・⭐、下：おへや／つくる／おみせ／なかま）
js/main.js                   描画ループ・カメラ（ドラッグ／ピンチ／ホイール）・つくる・まちの おみせ・すむひと・みため。テスト用 window.__town
js/data/quests.js            じゅうにんの おねがい（じょうけん と ごほうび）
js/data/mobs.js              モブじゅうにん 4にん（え は core.js の CH に たす）と しゅくだいの えらびかた
js/data/areas.js             エリア（まちレベルで ひらく とち）と まちレベルの けいさん
js/data/parts.js             まちの パーツ（まちの おみせ 専用カタログ。おへやの ITEMS とは別）・キャラの好きな場所 FAV
js/town/town.js              まちのデータ・置けるかの決まり・歩けるか・もどす（スナップショット）・保存
js/town/people.js            じゅうにん（家から出る→歩く→好きな場所・こうえん・ほかの住人へ→家に帰る。BFS で道を探す）・会話
js/render/art.js             じめん・たてもの・しぜん・こうえんの絵（Canvas 2D で描く）・アイコン
```
- core.js（クラシック）を読み、`S`（⭐・持ち物・着せかえ）、`save()`、`charSVG`、`ITEM`、`showPop`、`ACT` を使う。
- キャラの絵は `charSVG` を画像にして描く。モコ（`S.equip.char`）は おへやの服のまま。ほかのキャラは `S.looks[キャラ]` の服。

## 保存（`moko-town-v1`）
localStorage と IndexedDB（DB `moko-town`、ストア `kv`）に二重保存し、`t` が新しいほうを読む。localStorage にすぐ書き、IndexedDB は後から（待たない）。
```js
{ version:1, t, townName:'モコの まち', townLevel:1,
  unlockedParts:[おみせで かった パーツ id],     // むりょうの パーツは いれない
  ground:{"x,y":'road_dirt'|'water'|…},            // くさ いがいの じめん
  objects:[{id:'o12', type:'house_basic', x, y, r, look?:{roof,wall,door,window}, residents?:[キャラid],
            room?:{wall:'w_dots', floor:'f_wood', furn:['u_bed',…]}}],   // room＝おうちの なか（おへやの ITEMS の id）
  unlockedAreas:['central','forest',…], townLevel:さいこう レベル, camera:{x,y,zoom}, knownChars:[まちで しらせた キャラ], seq,
  quests:{done:[おわった おねがい id]}, templates:[{id, type, look, size?}] }   // look に shape（やねの かたち）・deco（かざり）、じぶんで つくる おうち は objects に size:[よこ,たて]
```
- 項目は追加のみ。パーツ id は変えない・消さない（知らない id も データには残る）。
- ⭐ は `moko-math-v1` の `points` だけを使う（まち専用の残高はない）。キャラの所持も `S.owned` を見る（まちで別に持たない）。

## まちの おみせ（おへやの おみせとは別）
- 下の「おみせ」か、まちの中の「まちの おみせ」をタップ。カテゴリ：おうち・やね・かべ・みち・しぜん・おにわ・こうえん・とくべつ。
- 買うのは「何個でも置ける権利」。`price:0` は最初から使える（買う画面には出さない）。値段は ⭐30〜450（設計書の案の3倍）。
- 購入の順番：**先に `unlockedParts` に入れて まちを保存 → それから ⭐ を減らして `save()`**。途中で止まっても「⭐だけ減って使えない」にはならない（逆に、まれに⭐が減らずに使えることはある）。
- 2回は買えない。⭐ が足りないときは「あと ⭐◯」と表示。

## つくる
- 「つくる」→ カテゴリ → パーツ（持っているものだけ。最後に「おみせで ふやす」）。
- もの：場所をタップ → 半透明のプレビュー（置けない所は赤）→ もう一度タップか「ここに おく」。
- じめん（みち・いけ・くさ）：指でなぞって塗る（2本指で地図を動かす）。「くさ」で みち・いけ を消せる。
- 「えらぶ」：置いたものをタップ → うごかす・まわす（さく・はし）・みため（家）・すむひと（家）・けす。モコの おうち と まちの おみせ は消せない（動かせる）。
- もどす／やりなおす（60回まで）。

## じゅうにん
- 家（`home:true`）をタップ → 「この おうちに だれが すむ？」。持っているキャラだけ。1けん 2にん まで。別の家を選ぶと引っ越し。
- モコ（いまのキャラ）は モコの おうち に住む。
- 歩けない所：家などの もの（花・くさむら・はし・にじ は歩ける）、みず（はしの上は歩ける）。
- キャラの好きな場所（`FAV`）によく行く：flower（花・花だん）、forest（木）、bench（ベンチ・ケーキやさん）、park（こうえん）。タップで おしゃべり。
- まちに来たとき、前回から増えたキャラを「あたらしい なかまが ふえたよ！」で知らせる。

## まちレベル・あたらしい とち
- まちの すてきポイント（`areas.js` の `scoreTown`）：おうち（8けんまで）×12、じゅうにん×15、置いた ものの しゅるい×6、しぜん（30こまで）×2、みち（60マスまで）×1、しせつ（こうえん・おにわ・とくべつ の しゅるい）×10。おなじ ものを たくさん置くだけでは あまり上がらない。
- レベル：120 / 250 / 400 / 580 / 800 ポイントで Lv2〜6（`LEVELS`）。上の「Lv」をタップで内訳。
- とち（40×40 の中）：Lv1 まんなか（x8〜31, y8〜31）→ Lv2 もり（上）→ Lv3 かわ（右）→ Lv4 うみべ（下）→ Lv5 おはなばたけ（左）。まだの とちは くもで おおい、置けない・歩けない。
- 初めて開いたとき、その とちの けしき（木・川と はし・すなはま と うみ・花）を、空いているマスにだけ置く（`openArea`）。`townLevel` は いちばん高かった レベルを保存し、一度開いた とちは閉じない。

## じゅうにんの おねがい（`quests.js`）
- 下の「💌 おねがい」。おわっていない おねがいを順番に3つ表示。たのむ ひとは じゅうにん（いなければ モコ）で、まちの中でその キャラの上に「！」。
- じょうけん（`check(town, PART)` → [いま, ひつよう]）を満たすと バッジ。「できた！ うけとる」で ごほうびの パーツ（`parts.js` の `quest:`。おみせでは売らない）が `unlockedParts` に入る。
- おねがい：おはな5こ → にじいろの はな／おうちを もう1けん → いど／こうえん → モコの どうぞう／みちで おうちを つなぐ → ふうしゃ／ベンチ2こ → ほしの がいとう／なかま3にん → メリーゴーランド／き10ぽん → ほしの き。

## モブじゅうにんの しゅくだい（`mobs.js`）
- こぶたの ブブ（さんすう）・たぬきの ポン（こくご）・ひよこの ピヨ（えいご）・かえるの ケロ（プログラミング）。家はなく まちを歩く。おへやの `ITEMS` には入れない（買えない・持ち物にならない）。
- しゅくだい：さんすう・こくご・えいご は その きょうかの 🏆テストの **れんしゅう**（オンの しゅるいから ランダム、テスト1〜3も ランダム。えいご は ABCで3つ以上おぼえた しゅるいだけ）。プログラミング は 開いている ステージから ランダム。
- 「てつだう」→ `sansu/index.html#hw=mob_pig|add21-2` のように開く → その れんしゅうの 画面が出る（core.js の `HW`）→ れんしゅうを最後まで（時間ぎれも）やると `S.hw[だれ]=じこく`（`hwDone()`）。プログラミングは `program/index.html#hw=mob_frog|ステージ` で、その ステージを クリアすると `moko-math-v1` の `hw` に書く。
- まちに戻ると `hwCheck()` が `S.hw[だれ] > 出したじこく` を見て おれい（⭐`HW_REWARD`＝10）。**かなえてから1じかん（`HW_COOLDOWN`）で** 新しい しゅくだい。
- 保存：まちは `moko-town-v1` の `mobs:{mob_pig:{key,label,at,doneAt}}`、おうちは `moko-math-v1` の `hw:{mob_pig:じこく}`（どちらも追加のみ）。

## ほんかくてきな いえづくり（フェーズ5）
- みため：やねの かたち（さんかく・まるい・たいら・とんがり・きのこ）、やねの いろ、かべ、ドア、まど、かざり（えんとつ・まどべの はな・ひさし・ハート・ほし・あかり・リボン。いくつでも）。かたち・かざりは まちの おみせ の「やね・かべ」で増やす。
- じぶんで つくる おうち（`house_custom`）：おおきさ 2×2・3×2・3×3・4×2・4×3 を選べる（ぶつかる大きさにはできない）。
- おきにいり（テンプレート）：みための「⭐ おきにいりに いれる」→「つくる」の おうち の先頭に出て、同じ みため・おおきさ の家を何けんでも建てられる（8こまで。× で外す）。
- 家のデザイン：ちいさな・きの・レンガの・2かいだての・きのこの・ケーキの・おしろの・じぶんで つくる おうち。

## おうちの なか
- 家をタップ →「なかを みる」。おへやと同じ形の部屋に、**おへやで持っている** かぐ・かべ・ゆか（`S.owned`）を置ける（持っているもの を使うので、おへやと同じ かぐを使っても減らない）。
- すんでいる キャラ（2にんまで）が部屋の中に表示される。絵は core.js の `roomSVG(st, mood, cls, chars)`（chars を渡すと そのキャラたちを描く。渡さなければ今までどおり）。

## 1マスずつ つくる（🧱 かべ・ゆか）
- つくる の カテゴリ「かべ・ゆか」（`cat:'room'`）。まちの じめんに 直接、家の間取りを作る。
- ゆか（`floor_wood`・`floor_tile`・`floor_carpet`）は じめん（`layer:'ground'`）。みちと同じく なぞって ぬる。
- かべ（`wall_wood`・`wall_white`・`wall_brick`・`wall_window`）は `paint:true` の 1×1 の もの。なぞった マスに 1こずつ置く（1回なぞる＝「もどす」1回）。あるけない。
- `door1`（あるける）・`table`・`chair`・`sofa`・`bookshelf`・`bed`。`bed` は `home:true, bed:true`：キャラが すめる（ベッドの下の マスから出入り）。みため・なかを みる は出さない。
- 保存は今までどおり `objects` と `ground` に入るだけ（形は変えていない）。

## パーツを足す
`js/data/parts.js` に1行足し、絵が必要なら `js/render/art.js` の `drawObject` に `case` を足す。ファイルを増やしたら `sw.js` の ASSETS と CACHE。
